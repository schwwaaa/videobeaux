# transraibe

## Description

AI-based transcription tool

## Arguments

- `stt_model`

## Program Template

```bash
videobeaux -P transraibe -i input.mp4 -o output.mp4 --stt_model VALUE
```

## Real World Example

```bash
videobeaux -P transraibe -i myvideo.mp4 -o transraibe_styled.mp4 --stt_model EXAMPLE
```
