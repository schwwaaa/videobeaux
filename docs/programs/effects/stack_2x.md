# stack_2x

## Description

Stack 2 videos on top of each other keeping the original orientation

## Arguments

- `input2`

## Program Template

```bash
videobeaux -P stack_2x -i input.mp4 -o output.mp4 --input2 VALUE
```

## Real World Example

```bash
videobeaux -P stack_2x -i myvideo.mp4 -o stack_2x_styled.mp4 --input2 EXAMPLE
```
