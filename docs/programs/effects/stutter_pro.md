# stutter_pro

## Description

Apply frame stutter effect with definable parameters

## Arguments

- `stutter`

## Program Template

```bash
videobeaux -P stutter_pro -i input.mp4 -o output.mp4 --stutter VALUE
```

## Real World Example

```bash
videobeaux -P stutter_pro -i myvideo.mp4 -o stutter_pro_styled.mp4 --stutter EXAMPLE
```
