triptych_examples.txt
======================

1) Basic horizontal triptych, audio from video 1
------------------------------------------------
videobeaux -P triptych \
  -i media/base.mp4 \
  -o out/triptych_hstack_v1_audio.mp4 \
  --input2 media/faith.mp4 \
  --input3 media/menino.mp4 \
  --layout hstack \
  --zoom1 1.0 --zoom2 1.0 --zoom3 1.0 \
  --audio-mode 1 \
  --vol1 1.0 --vol2 1.0 --vol3 1.0 \
  --force
